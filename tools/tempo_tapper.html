Tempo Tapper

Blind, repeatable hand-annotation of beat tempo. You tap the pulse you feel; the tool takes the median of your inter-tap intervals, so a missed or extra tap doesn't sway the result. It never shows the filename, the song type, or any algorithm's guess while you tap, so nothing anchors you.

  1. Set your initials (the rater id stored in the file).
  2. Choose your recordings folder. Order is randomised from a fixed seed, so a second rater on the same folder sees the same order.
  3. Tap Space to the beat for a few seconds, then Enter to save and advance. R redoes, P replays.
Rater initials
How tempo is computed. BPM = 60000 / median inter-tap interval (ms). The stability number is the spread of your taps; a wide spread is a prompt to redo, not an error. A random ~20% subset is flagged for a second pass so you can report your own consistency, and a second rater can run the same folder for inter-rater agreement.
